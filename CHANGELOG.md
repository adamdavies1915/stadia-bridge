# Changelog

## 0.1.0

- Windows desktop bridge from a Stadia controller to a native XInput Xbox 360 device.
- Automatic detection and reconnect, Start/Stop, adjustable stick deadzone,
  and a live output display.
- Neutralizes inputs and removes the virtual controller on Stop or disconnect.
- Centers the virtual sticks after the ViGEm startup handshake.
- Portable Windows x64 ZIP; Python is bundled. ViGEmBus is installed separately.
- Verified with a Bluetooth Stadia controller on Windows 11, including real
  button, stick, and independent trigger input through native XInput.
