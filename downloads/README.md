# Just want to play?

**[Download StadiaBridge.exe](https://github.com/adamdavies1915/stadia-bridge/raw/refs/heads/main/downloads/StadiaBridge.exe)**

Save the file and double-click it. Python and the app libraries are included.
Install [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases/latest) once if it
isn't already installed. Connect your controller and keep the app open while playing.

This is the Windows x64 single-file bundle. The executable is unsigned.
`SHA256SUMS.txt` contains its checksum.
